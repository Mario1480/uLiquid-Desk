# Plans

This directory separates work that is actively governed from work that is only queued.

- [`active/`](active/README.md) contains programs with unresolved implementation, rollout, migration, legal, security, acceptance, or production gates.
- [`backlog/`](backlog/README.md) contains proposals and legacy work lists that are not currently authoritative execution plans.
- Completed or superseded plans belong under [`../archive/plans/`](../archive/plans/README.md) after their current conclusions have been transferred to a status, architecture, runbook, or reference document.

Implementation completion alone is not an archive criterion. A plan remains active while any material release or operational gate is unresolved.
