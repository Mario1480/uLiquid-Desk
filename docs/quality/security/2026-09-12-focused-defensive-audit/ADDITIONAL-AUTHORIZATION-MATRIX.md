# Additional authorization matrix: mixed user/admin surfaces

These 34 concrete endpoints supplement the 142 explicitly privileged endpoints in [the main matrix](ADMIN-AUTHORIZATION-MATRIX.md). They expose a privileged branch, a server-derived administrator capability bypass, or protected self-service behavior. They are listed individually to avoid treating frontend presentation or a module-level label as authorization. No additional Next server actions exist in the inspected source.

Every row requires A (`requireAuth`, `apps/api/src/auth.ts:145`). Request role/admin flags do not grant authority. R applies to every row: current HTTP privilege is evaluated on the next request; role changes do not generally delete sessions or terminate in-flight work. Service methods trust the route-supplied principal; they are not independently authenticated network entry points. Normal users may call the ordinary owned operation, never the privileged diagnostic/configuration branch merely by setting client values.
