# Admin authorization matrix

Source audit dated 2026-09-12. Read with [the report](README.md). This is an explicit registration inventory, not a claim that every endpoint was exercised against a live server.

**A** = `requireAuth` in `apps/api/src/auth.ts:145`: database-backed session, expiry/idle checks, identity from stored session. CSRF applies to cookie-authenticated writes. **P** = `requirePlatformSuperadmin`, `apps/api/src/index.ts:4297`: stored user email matches deployment allowlist. **B** = `requireSuperadmin`, `index.ts:4306`: server-stored `admin.backendAccess` or P, plus `product.admin_advanced` entitlement. These names are intentionally distinguished; B is not platform-superadmin-only.

**G** = authorized global administration: caller ownership is intentionally not required; URL/query/body target IDs select the administered resource, not the actor. **T** = global administration targeting an explicit user/workspace/vault; lookup/DB constraints select the target; no caller-owner restriction is intended. Route-level target lookup and service calls are enumerated in [privileged actions](PRIVILEGED-ACTIONS.md). **R** = HTTP privileges re-read on the next request; changing a role/backend grant does not generally delete sessions. Already-running work and WebSockets are not synchronously revoked (M-01/M-04).

Client input does not grant P/B: `isAdmin`, `userId`, role fields or target IDs cannot replace the session identity. A valid session can send a direct HTTP request to every endpoint; the “normal user” column states whether it can pass the privileged check, irrespective of frontend hiding. A normal user here lacks platform/backend admin access, even if they own a workspace.

Guard placement is inside each listed handler immediately before protected work, except ULIQ's handler-chain wrapper and billing's explicit middleware. All rows include A. The endpoint function is the enclosing `register*Routes` function in the linked source. Session column R applies separately to each action. P/B objects are intentionally global; per-user ownership cannot be assumed for them.
