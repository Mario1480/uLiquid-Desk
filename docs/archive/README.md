# Documentation Archive

This directory contains completed plans and historical engineering evidence that is no longer the primary source of current operational truth.

Archive rules:

- Archive only after completion has been verified.
- Keep plans active while rollout, migration, deployment, legal, security, or production gates remain open.
- Move current conclusions into the relevant active status, ADR, runbook, or reference document before archiving.
- Preserve historical commands, identifiers, results, and evidence without silently rewriting facts.
- Update all inbound links when a document moves.

See [`tasks/README.md`](tasks/README.md) for dated task evidence.
