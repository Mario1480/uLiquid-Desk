# Archived Task Evidence

This directory contains dated, completed work records, smoke-test notes, implementation evidence, and incident follow-ups.

These documents are historical snapshots. They may contain open follow-up items, but the recorded task or observation window has ended. Use active feature status documents and runbooks for current decisions.

New completed task evidence should use the naming convention `YYYY-MM-DD-short-description.md` and be written in English.
