## Language migration

All new and materially updated repository documentation must be written in English. READMEs and central repository instructions have been normalized first. Existing German active documents should be translated when they are next materially updated or in a dedicated, evidence-preserving translation pass. Historical archived evidence may retain its original language to avoid changing the record.
